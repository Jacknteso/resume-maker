1. Overview

Resume Maker is an AI-powered web application that generates ATS-optimized resumes and personalized cover letters. Users fill in their details, optionally provide a job description (via URL or pasted text), and the app uses the Groq API (free Llama 3 / OpenAI OSS 120B model) to tailor the documents to the specific role.

The generated documents use clean, single-column HTML templates that parse well with Applicant Tracking Systems (ATS), and can be downloaded as professional PDFs.

Key advantage: The Groq API is completely free — no credit card required. It provides access to OpenAI OSS 120B (comparable to GPT-4) with fast inference speeds.

Request Flow

  1. User fills in personal info, education, experience, and skills on the form
  2. User provides a job description (URL or pasted text)
  3. On submit, the server scrapes the URL (if provided) or uses the pasted text
  4. The AI (Groq API) generates a tailored resume and cover letter
  5. User previews both documents side-by-side
  6. User downloads individual or combined PDFs

5. Setup & Installation

Prerequisites

  • Node.js v18 or higher
  • A free Groq API key from console.groq.com
  • npm (comes with Node.js)

Development Setup

# Clone the repository
git clone https://github.com/your-username/resume-maker.git
cd resume-maker

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Edit .env and add your Groq API key
# GROQ_API_KEY=gsk_your_key_here

# Start development server (with auto-reload)
npm run dev

# Or start without auto-reload
npm start

Open http://localhost:3000 in your browser.

Getting a Groq API Key: Visit console.groq.com, sign up (free, no credit card), create an API key, and paste it into your .env file.

8. Self-Hosting Guide (Docker)

Option 1: Docker Compose (Recommended)

# 1. Clone and enter the project
git clone https://github.com/your-username/resume-maker.git
cd resume-maker

# 2. Create environment file
cp .env.production .env
# Edit .env with your GROQ_API_KEY and SESSION_SECRET

# 3. Start everything (app + Nginx reverse proxy)
docker-compose up -d

# 4. Verify
docker-compose ps
curl http://localhost/health

# 5. View logs
docker-compose logs -f

The app will be accessible at:

  • HTTP: http://your-server-ip (port 80 via Nginx)
  • Direct: http://your-server-ip:3000 (bypassing Nginx)
  • Health Check: http://your-server-ip/health

Option 2: Docker Only (No Nginx)

# Build
docker build -t resume-maker .

# Run
docker run -d \
  --name resume-maker \
  -p 3000:3000 \
  -e GROQ_API_KEY=your_key \
  -e NODE_ENV=production \
  -e SESSION_SECRET=your_secret \
  resume-maker

Option 3: Manual Deployment (No Docker)

# Install production dependencies
npm ci --only=production

# Set environment variables
export NODE_ENV=production
export GROQ_API_KEY=your_key
export SESSION_SECRET=your_secret

# Start
node server.js

SSL/TLS (HTTPS)

  1. Obtain SSL certificates (e.g., Let's Encrypt with Certbot)
  2. Place them in nginx/ssl/ as fullchain.pem and privkey.pem
  3. Uncomment the HTTPS server block in nginx/conf.d/default.conf
  4. Update server_name to your domain
  5. Restart: docker-compose restart nginx

10. Health Monitoring

Health Check Endpoint

Available at GET /health, returns JSON with:

  • status: "ok" or "degraded"
  • timestamp: Current server time
  • uptime: Seconds since server start
  • memoryUsage: RSS, heap total, heap used
  • cpuUsage: User and system CPU time
  • environment: "development" or "production"
  • version: App version from package.json

Auto-degrades to "degraded" if essential directories are missing or memory usage exceeds 80%.

Docker Health Checks

Both the app container and Nginx container have built-in health checks that run every 30 seconds. Docker will automatically restart unhealthy containers.

Recommended Monitoring Tools

  • Uptime Robot (free tier available)
  • Pingdom
  • Prometheus + Grafana
  • Nagios

11. Template Customization

The resume and cover letter templates are defined in lib/templates.js.

Resume Template

  • Single-column layout (ATS-optimal)
  • Standard fonts: Calibri, Arial, Helvetica Neue
  • Sections: Header (name + contact), Summary, Experience, Education, Skills, Projects, Certifications
  • Clean section dividers with uppercase titles
  • Bullet points for experience descriptions

Cover Letter Template

  • Same font family as resume
  • Sender info block at top
  • Auto-generated date
  • Paragraph-based body
  • Signature line at bottom

PDF Generation

PDFs are generated with Puppeteer (headless Chromium). Configuration in lib/pdf.js:

  • Format: A4
  • Margins: 0.4in on all sides
  • Background rendering enabled
  • Runs with --no-sandbox flag (Docker-compatible)

12. Troubleshooting

ProblemSolution
Port 3000 already in use Change PORT in .env, or find and stop the process using that port: lsof -i :3000 (Linux/Mac) or netstat -ano | findstr :3000 (Windows)
"Failed to fetch job description" (403) Many sites (LinkedIn, Indeed) block scraping. Use the "Paste Job Description" textarea instead of the URL field.
PDF generation fails Ensure Puppeteer/Chromium is installed. In Docker, the Dockerfile handles this. Locally, run npx puppeteer install.
"Cannot GET /" Server may not be running. Check node server.js output for errors.
Docker permission issues Fix with: chmod -R 755 uploads output
Nginx 502 Bad Gateway The app container may be down. Check: docker-compose ps and docker-compose logs app
AI generation fails Verify your GROQ_API_KEY is valid and has quota. Check Groq dashboard at console.groq.com.
File upload fails Max file size is 10MB. Supported formats: PDF, DOCX, TXT, MD, RTF, DOC.
Session data lost Sessions are in-memory by default. Restarting the server clears all sessions. This is by design.
Important: Session data (generated resumes) is stored in-memory. It is lost when the server restarts. This is a privacy feature — no user data is persisted permanently.
